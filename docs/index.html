How it maps to the role

Keeping the store healthy

  • Audit of third-party scripts, app embeds and snippets left by removed apps
  • Core Web Vitals from real users (PageSpeed Insights), per-app blocking time
  • GA4 and Meta pixel through Shopify Customer Events, consent-aware

Building and improving

  • 21 editor-configurable sections, English and Bahasa Indonesia
  • Webhooks with HMAC checks: orders to a 3PL, low-stock alerts to Slack
  • Back-in-stock alerts through an App Proxy and the Admin API

Supporting campaigns

  • Launch check: oversell, misleading sale prices, discount timing, alt text
  • Countdowns in bar, hero and password page that go live on time
  • Built to stay fast under launch traffic: one font file, no blocking scripts
